## Platform halves

These are one contract with a website file and an app file. The app screen is not a second design.

| Piece | Why the app file cannot be the website file |
| --- | --- |
| VerticalEdgeLabel | React Native `Text` has no CSS `writing-mode`. The website uses `writing-mode: vertical-rl`. The app rotates the text. |
| MatrixTable | The website is an HTML `<table>`, so `colSpan` spans columns. React Native has no table element, so `colSpan` greater than 1 sets `flex`. |
| PatroYearEraToggle | The website year popup closes on `pointerdown`. The toggle calls `stopPropagation` on `pointerdown` and `preventDefault` only on `mousedown` (`preventDefault` on `pointerdown` swallows the click). `Box` does not forward those events, so the website file uses `div` and `button`. The app has no document popup. |
| SunTimesYearGrid | The website switches with Tailwind `lg` (1024px). The app uses `useWindowDimensions` and `width >= 1024`. `breakpoints` is not exported from `@vedic-patro/design-tokens`. |
