# Agent 1 handoff (shell)

Web is the look. Shared drawings are `@vedic-patro/ui/kit/shell` (`contract.ts`, `web/`, `native/`). Logic that was already in `packages/features` stayed there. New classes for the mobile-only screens are `packages/design-tokens/src/classes/shell/mobile-shell-classes.ts`.

## Shared in this branch

| Family | Where | App files |
| --- | --- | --- |
| Calendar header density | `calendar-header-classes`, `calendar-picker-classes` | The three web drift files no longer use `max-[419px]` / `min-[420px]`. They use the `xs` breakpoint (400px). |
| StatCard | `kit/shell` | Both copies deleted. Converter pages import the kit. |
| SeoContentSection | `kit/shell` | Thin binders kept at the old paths (below). |
| PatroHeaderTabs / PatroHeaderSwap | `kit/shell` | One-line re-exports. Native switches to the swap button below `breakpoints.xs` (was a hard-coded 420). |
| SiteFooter | `kit/shell` | Binders pass `onOpenPage` because the kit cannot import TanStack Router or Expo Router. |
| LanguageSwitcher | `LanguageButton` in `kit/shell` | Each app still performs its own language change (web loads the English bundle and writes the preference). |
| TodayHighlightCard | `kit/shell` | Binders supply the moon icon. The web `text-[2.75rem]` override is gone; the card uses `homeClasses.highlightDay` (`text-5xl`). |
| Mobile-only screens | `mobile-shell-classes` + `formatByteSize` / `parsePositiveYear` in `features/common` | `more`, `reminders`, `account/offline-data`, `day/[ad]` read the class map. |

## Left in the apps, and why

These pairs were not moved. Doing them honestly means sharing drawings that import another agent's folders, the app router, or Lucide as React components (the native kit cannot import `lucide-react`; icon nodes that were copied live in `kit/shell/icon-nodes.ts`).

| Component | Why it is still two files |
| --- | --- |
| PatroCalendarHeader, PatroDayTimeHeader, PatroDayTimePanel, PatroHeaderLocation | Drift classes are on the `xs` token. The drawings still take a panchanga location type and `locateDevice` from Agent 2's folder, and the web panel is a search form (no Input primitive in the kit). |
| PatroMonthYearNav, PatroYearHeader, PatroYearNavBlock | Web delegates to `PatroCalendarHeader` / `PatroYearNav`. Mobile delegates to `PatroDateNav` / `PatroYearBrowseNav`. The alias is one line; the shells are different components. |
| PatroTableShell | Both copies are under `dainikKranti/`, which is Agent 2. Not edited. |
| HomeQuickLinks, HomeVedaMantra, HomeRashifalSignPicker | Web uses TanStack `Link` and page search state. Mobile renders `QuickLinkTile` / its own picker. Hooks in `features/home` already hold the data. |
| AccountMenu, AuthDialog | Web dialog, social buttons, and form fields. Mobile uses `BottomSheetModal`, `EmailTextInput`, `PasswordInput`. `useAuthDialog` / `useAccountMenu` already exist. |
| MobileNavMenu | Web drawer vs the app navigation drawer. `useMobileNavMenu` already exists. |
| BsCalendarGrid | Month grid plus selection. Large, and the mobile grid is a different layout (`calendar-grid-layout.ts`). |
| BsNativeSelect | Web is a small native `<select>`. Mobile is a 400-line sheet picker used by Agent 2 and Agent 3. A re-export would not remove that drawing. |
| RelatedPageLinks | Web `Link` + Lucide components + learn icons. Mobile Expo Router + `AppNavIcon`. `useRelatedPageLinks` already exists. |
| VedicPatroLoader | Web is `<img src="/loader.svg">`. Mobile is a multi-layer animated SVG that imports `svg-motion` and `svg-defs` from the app. Sharing the caption hook is already done (`useVedicPatroLoader`). |

`StatCard` on native uses `View` for a computed percentage width. `Box` has no `style` prop.

## Needs for Phase 2 (do not edit these packages in this branch)

- Package export for class maps under `classes/shell/`. `"./classes/*"` only matches one path segment, so the mobile screens import `packages/design-tokens/src/classes/shell/mobile-shell-classes.ts` by relative path.
- An `Input` / `Field` primitive (web `<input>`, native `TextInput`) so location search, auth, and offline year fields can move into the kit.
- A `style` (or `width`) prop on `Box`, so `StatCard` does not drop to `View`.
- `lucide-react` must not be imported from `kit/*/native`. Keep passing `IconNode`, or allow a shared icon-node module.
- No new copy was required. Existing `t()` keys were enough.
