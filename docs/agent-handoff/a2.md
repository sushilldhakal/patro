## Copy and primitives

No new strings. `useLocale` from `@vedic-patro/i18n/react` and existing feature hooks supply the copy.

- `Pressable` does not forward a ref, so the planet menu trigger is a `button` on the website and a React Native `Pressable` in the app.
- `react-dom` has no declarations at the repo root, so the website menu's `createPortal` import carries `@ts-expect-error`.
- Kit `Card` does not take `onLayout`. The app timeline measures a `View` wrapped around `Card`.
- Kit `Text` does not take a `style`, so the app timeline uses React Native `Text` where a dynamic colour or the Devanagari font file is required. Font names come from `fontFamily.native`.
