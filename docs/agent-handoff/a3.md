## Web wins (where the apps differed)

- Rashifal meters use `Box widthPercent`. Domain tone classes stay on the website; the app maps them to the nearest `Icon` tone. Lucky grids take a `columns` prop. Profile picker: website `<select>`, app inline menu (the bottom sheet was dropped).
- Sait aside is the website list, not the app card grid. `location` is passed into the hook only on the app (the website uses it for the link search). No retry button. Ceremony day cards keep the website suitability ring. Native profile picker is an inline menu, not a bottom sheet.
- Shloka meaning is a disclosure, not the app accordion. Progress is `widthPercent`. Playback: website range input; the app passes its slider through `renderSeek` and the dock offset through `dockBottom`.
- Profile form uses the kit `Input`. Place search is `renderPlace` (website `CityAutocomplete`, app `PatroHeaderLocation`). Gender and era stay a `<select>` on the website and chips in the app, because the hook already exposes both. Kundali profile picker uses `Sheet` plus `bindOpen`; the app file keeps `forwardRef`. Milan scores are a table on the website (the kit `Table` has no colspan) and a stacked list in the app, with `obtained/max`.
- Owner compatibility keeps each app's day fetch (`fetchPanchangaDay` vs `fetchPanchanga`) so the numbers do not change. House requirements: website `<select>`, app `NativeStringSelect` via `renderSelect`.
- Section nav default variant stays per app (website `sidebar`, app `horizontal`) because callers omit it. Sidebar subnav links are `renderLink`. House detail is one `Sheet` (the website dialog and the app drawer were both app chrome). Accordion sections in that dialog are disclosures. Shanti tile glyphs use the shared icon set. The graha colour bar is data (`colorHex` from the API), not a token.
- Divisional compare: website draws `<select>`; the app passes `NativeStringSelect`. The chart, status legend, and bhava table are slots. The app still wraps the block in `KundaliSection`; the website does not.
- Compact section headers on the app kundali detail were dropped. Titles stay visible, matching the website.
- Graha and rashi artwork stay app components (`renderGraha` / `renderRashi`). Extra nakshatra glyphs that only the app graha table drew were dropped.
