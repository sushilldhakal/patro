## Missing primitives and copy

Do not edit `packages/ui/src/{contract,web,native}` or `packages/i18n` for these. Built locally where this agent needed them:

- **Input.** No kit field. `DocumentJumpForm` uses `<input>` on the website and `TextInput` in the app, styled with `documentsClasses.jumpInput`.
- **Disclosure button.** `Pressable` has no `aria-expanded`. `SaitRulesSection` uses a `<button aria-expanded>` on the website and React Native `Pressable` with `accessibilityState.expanded` in the app.
- **Switch.** App `Switch` is Radix (`apps/web/src/components/ui/switch.tsx`) with `[Npx]` sizes. The rules section uses a local thumb switch and `saitClasses.ruleSwitch*`.
- **Icon on a secondary button.** `Icon` tones have `secondary` (the fill) but not `secondaryForeground` (the label colour). The jump button draws the search glyph with `text-secondary-foreground` on the website and `mobileRoles().secondaryForeground` in the app. A `secondaryForeground` tone on `Icon` would remove that local SVG.
- **Router.** `@tanstack/react-router` does not resolve from `packages/ui` (it is not a dependency, and `package.json` was not edited). Jump and card navigation is an `onJump` / `onPress` from the page. The card still renders a real `href` for a new tab and for prerender.

No new i18n keys. Copy still comes from the existing feature hooks (`useSaitSources`, `useSaitRules`, `useDocumentJumpForm`, `useDocumentCard`, `useLocale` / `t`).
