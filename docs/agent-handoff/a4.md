## Left in the apps, and why

Not rewritten. The domain README already treats these as platform code: pixel
space on the website, unit space in the app, different texture and tile loading.

- **3D scenes and playgrounds:** `DaySimScene`, `TwoSystemsScene`, `TwoSystemsStudy`,
  `SunEarthMoonOrbit`, `DayChapterPlayer`, `AakashGocharScene`, and the mobile
  `LearnCanvas` / `GeocentricSkyCanvas` halves. `DayChapterPlayer` is the
  playback chrome wrapped around that scene (there is no separate learn
  `PlaybackBar`; the documents `PlaybackBar` belongs to Agent 3).
- **SVG diagrams** that are not the same drawing: `EotGraph`, `EarthRotationDiagram`
  (website SVG + `EarthGlobeImage`, app a different SVG), `EclipticWheel`
  (two mobile copies as well as the website), `ServerPipelineDiagram`,
  `CompassControl`, `SkyTimeSheet`. Compass and the time sheet already read
  `packages/features/src/sky3d` for behaviour.
- **`sun-earth-moon-math.ts`** (website and `apps/mobile/lib/learn`) is the
  same Kepler idea with different scales and a flipped moon Y. Not byte-identical.
  `eclipse-math.ts` uses synodic month `29.530589`; the shared sky constant in
  `packages/domain/src/sky3d/two-systems.ts` is `29.530588`. Left as-is.
- **`hips-config`** stays per app (different tile base URL), as requested.
- **Learn hub** (`apps/web/src/pages/Learn.tsx`, `apps/mobile/app/(tabs)/learn/index.tsx`):
  behaviour is already `useLearnHub`. The cards differ by icon set (Lucide vs
  Ionicons) and by router (`Link` vs `expo-router`), and the website page uses
  shell pieces this agent does not own (`PageShell`, `Input`).
- **`LearnMoreCard`:** the website file is `apps/web/src/components/LearnMoreCard.tsx`
  (Agent 1's root components; also used by Panchanga, Ritu, documents). Not
  edited. The app copy is `apps/mobile/components/learn/LearnMoreCard.tsx`.
  Behaviour is already `useLearnMoreCard` in `packages/features/src/common`
  (Agent 1). Phase 2 can move the drawing once that web file is free.

No new i18n keys. No new core UI primitives. `apps/mobile/components/panchanga/WheelChart.tsx`
fails `tsc` (`Defs` children, `paintOrder`) and `check:design` reports hex/rgb
there plus arbitrary sizes in the patro date headers. Those files are not in
this area; they fail on this branch without any edit from Agent 4.
