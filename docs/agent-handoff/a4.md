## Still two copies, and why

- **`EclipticWheel` and `GuideGrid`** (`apps/web/src/components/learn/EclipticWheel.tsx`, `apps/mobile/components/learn/EclipticWheel.tsx`, and a third copy at `apps/mobile/components/learn/playground/EclipticWheel.tsx`). They are not a flat figure. Each returns a Three.js object graph (`THREE.Group`, `LineSegments`, `Mesh`, `meshBasicMaterial`, `depthTest`, `renderOrder`) that `DaySimScene` and `AakashGocharScene` parent into a WebGL scene. Belt radii and the builders used by the website file and the app scene file already live in `packages/domain/src/learn/ecliptic-wheel-geometry.ts`. The playground copy still inlines those builders and also exports `atLonInto`. The website's copy of that helper is `apps/web/src/lib/sky3d/ecliptic-position.ts`. This pass cannot edit `sky3d/`, and an SVG replacement would remove the mesh the day scene mounts.
- **`CompassControl` and `SkyTimeSheet`.** Both copies are under `components/sky3d/`. This pass cannot edit that tree.
- **3D / texture scenes left as two halves on purpose:** `DaySimScene`, `DayChapterPlayer` (`DayChapterBar`, `DayChapterWelcome`), `TwoSystemsScene`, `TwoSystemsStudy`, `hips-config`, and the Sun–Earth–Moon pixel-versus-unit maths (`sun-earth-moon-math.ts` in each app).
- **Reference tables** with the same names in `PanchangaReferenceGuide.tsx` and `apps/mobile/components/learn/diagrams/ReferenceTables.tsx`: `RashiReferenceTable`, `NakshatraReferenceTable`, `TithiReferenceTable`, `YogaReferenceTable`, `KaranaReferenceTable`, `GrahaReferenceTable`. Not part of this pass's move list.
